# 🌿 PhytoMeasure · 植物显微切片测量 Web 应用

在浏览器中上传植物显微切片图片，完成像素—微米定标后，圈选多个细胞的外轮廓及其孔洞，
自动计算**扣除孔洞后的净面积（μm²）**与**含孔洞边界的总周长（μm）**，
并可发布为不可变报告、导出**标注 PNG** 和**测量 CSV**。

- 技术栈：Node.js（Express）+ SQLite（better-sqlite3）+ 原生 Canvas 前端
- 图片与数据**全部本地保存**（无任何外部服务依赖）：
  - 数据库：`data/app.db`
  - 原始图片：`data/images/`
  - 发布时的图片快照：`data/snapshots/`
  - 标注 PNG / CSV 在导出时实时生成

## 功能说明

1. **图片上传**：支持 PNG / JPEG / WebP（≤ 30 MB），读取真实像素尺寸。
2. **标尺定标**：在原图上点选**两个不同的像素点**，输入它们的实际微米距离，
   得到每像素微米数（μm/px）。两点重合、坐标越界、距离非正数均会被拒绝，且整次修改不生效。
3. **细胞轮廓**：可圈选多个细胞外轮廓，每个细胞可包含多个孔洞。
   - 轮廓不得**自交/自接触**，顶点不得**越出图片**；
   - 孔洞必须**严格位于**所属外轮廓内部（不能贴着外轮廓边界）；
   - 同一细胞的孔洞之间**不得接触或重叠**；
   - 任意一个对象不合法时，服务端会指出具体细胞/孔洞编号与原因，**整批轮廓保存不生效**。
4. **测量结果**：
   - 净面积 =（外轮廓面积 − 全部孔洞面积）× (μm/px)²，单位 **μm²**；
   - 总周长 =（外轮廓周长 + 全部孔洞周长）× μm/px，单位 **μm**；
   - 缩放、平移视图只改变显示，不改变任何测量值。
5. **重新定标**：草稿中的所有轮廓立即按新比例重算测量值。
6. **发布与乐观并发**：
   - 发布会冻结当时的**图片副本、标尺、轮廓与测量结果**，之后修改草稿不影响已发布报告；
   - 发布请求必须携带**读取时的草稿版本号**；期间草稿被改动（版本过期）时请求被拒绝（HTTP 409），
     页面会自动拉取最新草稿，需确认后重新发布。
7. **导出**：在「已发布报告」页勾选报告，可导出
   - 单份或多份合并的**测量 CSV**（UTF-8 BOM，Excel 直接可读）；
   - 单份**标注 PNG**（彩色细胞轮廓、红色虚线孔洞、细胞编号与青色标尺）；
   - 多份报告的 **ZIP**（每份一张标注 PNG + 一份 CSV，外附汇总 CSV）。
8. **报告间比较**（本轮新增）：在「已发布报告」页选择**两份不同报告**作为
   **基线**与**复测**，按细胞**手动一对一配对**后保存为比较记录：
   - **同名细胞不会自动配对**——每对都必须在页面两侧下拉框中手动选择；
     已被其他配对选用的细胞会自动置灰，服务端对配对重复、细胞不存在等情况整次拒绝；
   - 比较只取两份报告**发布时冻结的定标与测量值**（页面同时展示两侧各自的 μm/px），
     逐对列出**净面积、总周长**的基线值、复测值、**带符号差值**（复测 − 基线）
     与**相对基线变化率**；**基线值为零时变化率显示“不可计算”**；
   - 未参与配对的细胞在页面与 CSV 中按**基线未配对 / 复测未配对**分别列出；
   - 修改比较记录必须携带**读取时版本号**，过期修改返回 HTTP 409 与当前版本，需重新打开再改；
   - 报告不存在、两侧为同一份报告、配对重复或引用不存在的细胞时，**整次保存不生效**；
   - 比较结果可导出**与页面一致的 CSV**（配对段 + 两侧未配对段，UTF-8 BOM）；
   - 比较记录只保存报告 ID 与细胞 ID 配对，数值始终由冻结报告重算——
     **草稿后续改动或另发新报告都不会改变已存比较**。

## 配置项

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 容器/服务监听端口 |
| `DATA_DIR` | `./data`（Docker 中为 `/app/data`） | SQLite、原始图片、快照的保存目录 |
| `HOST_PORT` | `8080` | 仅 Compose 使用：宿主机映射端口 |

> 本轮新增的比较记录功能**不引入新的环境变量**；比较记录保存在同一个
> SQLite 数据库（`comparisons` 表，启动时自动建表，旧数据库直接升级，无需迁移）。

## 一条命令启动（Docker Compose）

```bash
docker compose up -d --build
```

启动后浏览器访问：

```
http://localhost:8080
```

若 8080 端口被占用：

```bash
HOST_PORT=8088 docker compose up -d --build
# 然后访问 http://localhost:8088
```

数据持久化在 Docker 命名卷 `phytomeasure-data` 中。
若希望直接在宿主机目录查看数据，可把 `docker-compose.yml` 中的卷改为绑定挂载：

```yaml
volumes:
  - ./data:/app/data
```

停止与查看日志：

```bash
docker compose down
docker compose logs -f
```

## 非 Docker 方式运行（需 Node.js ≥ 20）

```bash
npm install
npm start
# 访问 http://localhost:8080
```

## 使用步骤（网页操作）

1. 首页上传图片，自动进入编辑器；
2. 选择 **📏 定标点工具**，在图上单击两个点，在弹窗中输入实际距离（μm）；
3. 选择 **⭕ 画细胞外轮廓**：单击逐个加点，双击（或回车）闭合；
4. 在细胞列表中选中某个细胞，用 **🕓 为选中细胞画孔洞** 工具绘制其孔洞；
5. 点击 **保存全部轮廓**——若有非法轮廓/孔洞，顶部红条会指出具体对象，本次保存整体不生效；
6. 右侧测量表实时显示净面积与总周长，滚轮缩放、拖拽平移不影响数值；
7. 点击 **发布当前草稿为报告**，在「已发布报告」中查看冻结快照并导出 PNG / CSV；
8. 至少发布两份不同报告后，在「已发布报告」页点击 **📊 新建报告间比较**，
   选定基线与复测报告，逐行 **+ 添加一对** 并在两侧下拉框手动选择细胞
   （同名不会自动配对；未选细胞保留在下方未配对区），点击 **保存比较记录**；
9. 打开比较记录查看每对细胞两侧数值、带符号差值与变化率（基线为零显示“不可计算”），
   可导出与页面一致的 CSV，或点 **修改比较记录** 调整配对（须基于最新版本，过期会被拒绝）。

## 目录结构

```
.
├── Dockerfile
├── docker-compose.yml
├── package.json
├── server/
│   ├── index.js       # Express API：上传/定标/轮廓/发布/导出/报告比较
│   ├── db.js          # SQLite 表结构与初始化（启动自动建表，含 comparisons）
│   ├── geometry.js    # 几何校验与面积/周长计算（服务端最终校验）
│   ├── comparisons.js # 比较配对校验与冻结值差值/变化率计算
│   ├── render.js      # sharp + SVG 渲染标注 PNG
│   └── exporter.js    # CSV（测量/汇总/比较）与 ZIP 导出
├── public/            # 前端（原生 JS，无需构建；compare.js 为比较页面）
├── test-geometry.js          # 几何自测
├── test-comparison-unit.js   # 比较模块单元自测（差值/变化率/零基线/CSV）
├── test-comparison.js        # 比较功能端到端自测（真实 HTTP 服务）
└── data/              # 运行后生成：app.db、images/、snapshots/
```

### 比较功能 HTTP API

| 方法与路径 | 说明 |
| --- | --- |
| `GET /api/comparisons` | 比较记录列表（不含计算明细） |
| `POST /api/comparisons` | 新建：`{baselineReportId, retestReportId, title?, pairs:[{baseCellId, retestCellId}]}`；报告不存在、两侧相同、配对重复/细胞不存在均 400，整次不写入 |
| `GET /api/comparisons/:id` | 比较详情（配对差值/变化率 + 两侧未配对细胞）；不存在返回 404 |
| `PUT /api/comparisons/:id` | 修改：须携带 `version`（读取时版本）；过期返回 409 与 `currentVersion`，校验失败整次不生效 |
| `GET /api/comparisons/:id/csv` | 导出与页面一致的比较 CSV（UTF-8 BOM） |
